How I work

I’m a full-stack developer who ships complete products alone — spec, schema, backend, frontend, deploy, and a written handover the owner can act on. Recent work spans New Zealand and the Philippines: a TCG marketplace, a Korean grocery storefront with an in-store POS, a real-time budget tracker with native mobile wrappers, and a set of static sites for local businesses.

  • AI-assisted, not AI-abandoned. I use coding agents to move faster, then read every line, keep parallel implementations in sync, and own the result.
  • Production is the deliverable. Every project has a deploy story — Vercel, Convex, Postgres, Supabase — plus caching, auth, and env config sorted, not left as a TODO.
  • Handover matters. READMEs, schema files, and ownership-transfer notes so a client isn’t locked to me.
