TradingBot / paper trading test

EMA crossover strategy, simulated with fake money against live Binance prices.

Simulated only. No real orders are ever placed. No API key required or accepted.

Session setup

Defaults (1m candles, EMA 9/21) are tuned to produce a crossover within minutes so you can watch the mechanics work — not for realistic profitability. Slower EMAs on longer candles (e.g. 15m/20/50) are less noisy but a crossover might not happen for hours. The Trend EMA only lets buy signals through when price is above that long EMA (an "is this an uptrend?" gate); set it to 0 to trade the raw crossover. ATR stop × places the stop that many Average-True-Range units below entry and ATR trail × ratchets it up under the high-water mark (0 on either falls back to the fixed Stop-loss %). Risk % / trade sizes each entry so hitting the stop loses that % of the balance (0 = flat "Quote per trade").
